::: info Síntesis de la unidad
Esta unidad está centrada en el estudio de las estructuras condicionales, incluyendo los bucles. Los condicionales son fundamentales en la programación y permiten separar diferentes ejecuciones dependiendo de los datos de entrada introducidos, mientras que los bucles nos permiten repetir instrucciones de manera controlada. Aprenderéis cuándo y cómo utilizar estas estructuras, así como sus aplicaciones prácticas para resolver problemas de forma eficiente.
:::

## 📋 Objetivos del Curso {.animate-title}

::: tip Objetivos cubiertos y relación con RA

Este tema se centra en el uso de estructuras que establecen ejecuciones alternativas dependiendo de los datos de entrada y de estructuras que permiten repetir bloques de código, un concepto fundamental en la programación para automatizar tareas.

- Objetivo 3.1: Escribir código con estructuras de control alternativas (condicionales).
- Objetivo 3.2: Escribir código que haga uso de bucles **`for`** para iterar sobre un rango de valores o una colección.
- Objetivo 3.3: Utilizar los bucles **`while`** y **`do-while`** para repetir la ejecución de un bloque de código basándose en una condición.
- Objetivo 3.4: Reconocer y emplear sentencias de salto, como **`break`** y **`continue`**, para modificar el flujo de ejecución de un bucle.
- Objetivo 3.5: Desarrollar programas que combinen diferentes estructuras de control (condicionales y repetitivas) para resolver problemas.
