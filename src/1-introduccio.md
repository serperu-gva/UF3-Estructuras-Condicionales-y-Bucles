# 1. Introducción

Las estructuras condicionales son la base de cualquier lenguaje de programación, ya sea imperativo, declarativo u Orientado a Objetos como Java. Entre estas estructuras de control en Java destacan las estructuras `if`, `if-else`, `switch` y los bucles, que son utilizados como un recurso fundamental. Los bucles son estructuras de control que permiten repetir un conjunto de instrucciones varias veces. Esta repetición se realiza mientras se cumple una determinada condición o hasta que se cumple una condición específica, según el tipo de bucle utilizado. Si el bloque que se va a repetir contiene más de una instrucción, es habitual agruparlas mediante un delimitador de bloque (como llaves `{}` u otros símbolos según el lenguaje).

- `Estructura Condicional if`
- `Estructura Condicional if-else`
- `Estructura Condicional switch`
- `Bucle for`
- `Bucle while`
- `Bucle do-while`

Todo problema que requiera más de una solución diferente dependiendo de la entrada del programa deberá utilizar una estructura condicional, de manera que cada ejecución ejecutará algunos bloques de código diferentes en cada caso.

Por otra parte, todo problema que requiera repetición puede realizarse con cualquiera de los tres bucles existentes, pero según el caso suele ser más sencillo o intuitivo utilizar uno u otro.

Como regla general, es recomendable:

- Utilizar el bucle **`for`** cuando se conozca de antemano el número exacto de veces que debe repetirse el bloque de instrucciones.
- Utilizar el bucle **`while`** cuando no sepamos el número de veces que debe repetirse el bloque y sea posible que no tenga que ejecutarse ninguna vez.
- Utilizar el bucle **`do-while`** cuando no sepamos el número de veces que debe repetirse el bloque y deba ejecutarse al menos una vez.

Estas reglas son generales y, normalmente, se utilizarán unas estructuras u otras en función de las necesidades. Pero hay que tener en cuenta que, con mayor o menor esfuerzo, puede utilizarse cualquiera de ellas.
