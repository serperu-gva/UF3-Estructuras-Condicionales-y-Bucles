# 1. Introducció

Les estructures condicionals són la base de qualsevol llenguatge de programació ja siga imperatiu, declaratiu o Orientat a Objectes com Java. Entre este estructures condicionals en Java destaquen les estructura if, if-else, switch i els bucles, que son utilitzats com un recurs fundamental. Els bucles són estructures de control que permeten repetir un conjunt d'instruccions diverses vegades. Aquesta repetició es realitza mentre es compleix una determinada condició o fins que es compleix una condició específica, segons el tipus de bucle utilitzat. Si el bloc a repetir conté més d'una instrucció, és habitual agrupar-les mitjançant un delimitador de bloc (com ara claus {} o altres símbols segons el llenguatge).
- `Estructura Condicional if`
- `Estructura Condicional if-else`
- `Estructura Condicional switch`
- `Bucle for`
- `Bucle while`
- `Bucle do-while`

Tot problema que requerisca de més d'una solucio diferent depenent de la entrada del programa, haura de fer servir una estructura condicional, de manera que cada execució executarà alguns blocs de codi diferents en cada cas.
Per altra banda, tot problema que requerisca repetició pot fer-se amb qualsevol dels tres bucles existents, però segons el cas sol ser més senzill o intuïtiu utilitza l'un o l'altre.  
Com a regla general és recomanable:

- Utilitzar el bucle **`for`** quan es conega per endavant el nombre exacte de vegades que ha de repetir-se el bloc d'instruccions.
- Utilitzar el bucle **`while`** quan no sabem el nombre de vegades que ha de repetir-se el bloc i és possible que no haja d'executar-se cap vegada.
- Utilitzar el bucle **`do-while`** quan no sabem el nombre de vegades que ha de repetir-se el bloc i deurà executar-se almenys una vegada.

Aquestes regles són generals i, normalment, s'usarà unes estructures o altres en funció de les necessitats. Però cal tindre en compte que, amb major o menor esforç, pot utilitzar-se qualsevol d'elles.
